# TITO System Check ⚙️📊 [Active Build]

A lightweight, portable, and real-time Windows system monitoring application built in Python. Inspired by modern Windows 11 design principles, this tool provides essential hardware metrics without requiring administrative privileges.

> 🚧 **Project Status: Active Development / In Build**  
> This repository contains the ongoing development of the TITO System Check utility. Features are being built, tested, and shipped incrementally.

## 🚀 Target Features

- **Real-Time Monitoring:** Live tracking of CPU usage, RAM utilization, disk activity, and core system metrics.
- **Dynamic Visuals:** Built-in live graphs that update seamlessly to show performance spikes and trends.
- **Modern UI:** A clean, Windows 11-inspired interface supporting both Light Mode and Dark Mode.
- **Zero Installation:** Fully portable execution—no registry clutter or heavy framework dependencies.
- **Safe & Standard:** Designed to run entirely in user space without requiring administrator permissions.
- **Backward Compatibility:** Fully compatible with both Windows 10 and Windows 11.

## 🛠️ Tech Stack

- **Language:** Python
- **Core Architecture:** Lightweight Windows integration, system metric polling, and portable architecture.
- **Target OS:** Windows 10 / 11
